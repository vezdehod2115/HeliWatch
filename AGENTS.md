# AGENTS.md

Правила работы над HeliWatch (Android-приложение на Tauri v2) — для всех агентов и участников проекта.

## Обязательное правило

ПРАВИЛО GIT (коммит): В конце этапа выполняй git add . и git commit -m "..." двумя ОТДЕЛЬНЫМИ вызовами терминала (не используй &&, в Windows PowerShell это вызывает ошибку).

ПРАВИЛО GIT (пуш): После выполнения git commit всегда отправляй изменения на GitHub отдельной командой git push (не объединяя её через &&, в Windows PowerShell это вызывает ошибку). Работа не считается завершённой, пока изменения не отправлены на GitHub.

## Как это применяется

- Этап или задача считаются завершёнными только после коммита и пуша: работа без коммита и без `git push` не сдаётся.
- Перед коммитом: сборка и проверки проходят, статусы в `PLAN.md` и запись в `CHANGELOG.md` обновлены (если этап/фикс этого требует).
- Сообщение коммита — краткое и по сути изменений, например: `этап 1: каркас, два WebView, тач-роутинг, тема`.
- Порядок и формат вызовов: `git add .`, затем `git commit -m "..."`, затем `git push` — каждый отдельным вызовом терминала, без объединения через `&&`.
- Архитектура, протокол, версии и этапы — в [PLAN.md](PLAN.md); журнал изменений — в [CHANGELOG.md](CHANGELOG.md).
