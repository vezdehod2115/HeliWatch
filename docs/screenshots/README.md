# Скриншоты

Файлы `01…14*.jpg` появятся по мере готовности этапов. Требования: JPG,
1080×2340 (портрет) и 2340×1080 (ландшафт), без рамок телефона, с реальным
интерфейсом на тёмной теме.

Список и подписи — в [README.md](../../README.md#скриншоты), там же указан этап
для каждого кадра. Для этапа 0.1.0 создайте папку `stage-01/` и снимите:

| Файл | Что показать |
|---|---|
| `01-main.jpg` | тестовая страница, верхняя и нижняя панели, видео |
| `02-touch-zones.jpg` | экран «Отладка → зоны касания» |
| `03-keyboard-react.jpg` | клавиатура в поле React-панели |
| `04-keyboard-site.jpg` | клавиатура в поле сайта |
| `05-landscape.jpg` | поворот экрана |
| `06-youtube.jpg` | YouTube под оверлеем, логин/куки |
| `07-file-picker.jpg` | системный выбор файла |
| `08-back-toast.jpg` | предупреждение перед выходом по back |

Команда съёмки с подключённого телефона:

```powershell
adb exec-out screencap -p > docs/screenshots/stage-01/01-main.jpg
```

Не сжимайте скриншоты до размытия: JPG качества 90 достаточно.
