# Логотип HeliWatch

Выбран вариант **B «H-плеер»**: монограмма H, у которой перекладина заменена
треугольником play. Он читается в 16–24 px, уникален, точно ложится в адаптивную
иконку Android и анимируется в сплэше (появится на этапе 4).

## Варианты из плана

| Вариант | Идея | Итог |
|---|---|---|
| A «Два экрана» | два скруглённых экрана, в пересечении — play | горизонтальный локап для README/OG |
| **B «H-плеер»** | монограмма H, перекладина — play | **выбран**: знак, иконка, фавикон |
| C «Плей и два круга» | участники вокруг play-кнопки | отклонён: круги сливаются в малом размере |

Мотивов вертолётов, винтов и чужих логотипов нет.

## Файлы

- `logo-mark.svg` — знак 512×512 (используется в React-панели и README);
- `logo.svg` — горизонтальный локап 1120×320 для README/OG;
- `icon-source.png` — 1024×1024, источник для `pnpm icons` (генерация — Pillow:
  суперсэмплинг 4096 → LANCZOS 1024, скруглённый квадрат + две стойки + треугольник);
- `android/foreground.svg` — слой foreground адаптивной иконки (safe zone 66%);
- `android/background.svg` — фон адаптивной иконки (тёмный радиальный градиент и
  две тонкие окружности).

Иконки Android: `pnpm icons` (tauri icon) обновляет `mipmap-*`;
`pnpm android:patch` добавляет `mipmap-anydpi-v26/ic_launcher*.xml` с
background/foreground/monochrome. Monochrome-слой использует тот же вектор —
его тонирует система (Android 13+ themed icons).

## Палитра

| Токен | Значение | Где |
|---|---|---|
| Фон | `#06201D` | окно, иконка, панели |
| Акцент | `#6FF0C4` | знак, кнопки, активные состояния |
| Текст | `#E9FFFA` | основной текст |
| Вторичный текст | `#9DBFB7` | подписи |
| Ошибка | `#FF8494` | отладочные зоны, ошибки |

Правило: визуальная тема живёт в `src/styles/theme.css` (`@theme`), брендинг —
здесь. Новые цвета не хардкодятся в компонентах.
