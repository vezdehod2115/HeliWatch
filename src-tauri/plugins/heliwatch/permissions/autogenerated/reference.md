## Default Permission

Базовые разрешения HeliWatch: управление сайтом, тач-роутинг и события

#### This default permission set includes the following:

- `allow-site-init`
- `allow-site-load`
- `allow-site-nav`
- `allow-site-cmd`
- `allow-site-regions`
- `allow-site-info`
- `allow-register-listener`
- `allow-remove-listener`
