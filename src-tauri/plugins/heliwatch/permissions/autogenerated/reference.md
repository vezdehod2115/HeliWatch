## Default Permission

Базовые разрешения HeliWatch: сайт, тач-роутинг, события, PiP и фон

#### This default permission set includes the following:

- `allow-site-init`
- `allow-site-load`
- `allow-site-nav`
- `allow-site-cmd`
- `allow-site-regions`
- `allow-site-info`
- `allow-pip-update`
- `allow-pip-enter`
- `allow-session-start`
- `allow-session-update`
- `allow-session-stop`
- `allow-session-info`
- `allow-keep-screen-on`
- `allow-register-listener`
- `allow-remove-listener`
